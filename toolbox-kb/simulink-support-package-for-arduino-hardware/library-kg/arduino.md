# Arduino

Use these blocks for arduino.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Advanced | arduinorootlib/Advanced | R2023b+ | Access advanced Arduino features — use for interrupts, timers, or low-level hardware control beyond basic I/O on Arduino boards |
| Arduino Motor Carrier | arduinorootlib/Arduino Motor Carrier | R2023a+ | Interface with the Arduino MKR Motor Carrier board — use for controlling DC motors, servos, and encoders via the dedicated motor shield |
| Common | arduinorootlib/Common | R2023a+ | Access common Arduino I/O blocks — use for digital/analog read/write, PWM output, and basic pin control on any Arduino board |
| Communication | arduinorootlib/Communication | R2024b+ | Access communication interfaces on Arduino — use for I2C, SPI, or serial communication with external sensors and devices |
| Ethernet Shield | arduinorootlib/Ethernet Shield | R2023a+ | Access Ethernet connectivity via Arduino Ethernet Shield — use for TCP/IP or UDP network communication in Arduino-based projects |
| Sensors | arduinorootlib/Sensors | R2023a+ | Access sensor modules for Arduino — use for reading data from common sensors like IMU, temperature, ultrasonic distance, or GPS |
| Utilities | arduinorootlib/Utilities | R2023a+ | Access Arduino utility functions — use for timing, system reset, or board-specific configuration on Arduino hardware |
| WiFi | arduinorootlib/WiFi | R2023a+ | Access WiFi connectivity on Arduino WiFi-capable boards — use for wireless TCP/IP or UDP communication in IoT applications |

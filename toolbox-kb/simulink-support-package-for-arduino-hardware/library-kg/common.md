# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Access common Arduino I/O blocks — use for digital/analog read/write, PWM output, and basic pin control on any Arduino board | Common | Simulink Support Package for Arduino Hardware |
| Access communication interfaces on Arduino — use for I2C, SPI, or serial communication with external sensors and devices | Communication | Simulink Support Package for Arduino Hardware |
| Access sensor modules for Arduino — use for reading data from common sensors like IMU, temperature, ultrasonic distance, or GPS | Sensors | Simulink Support Package for Arduino Hardware |

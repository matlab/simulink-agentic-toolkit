# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read the state of a digital input pin on a TI RM57Lx ARM Cortex-R processor — use to sample GPIO pin state for discrete input signals | Digital Read | Embedded Coder Support Package for ARM Cortex-R Processors |
| Set the state of a digital output pin on a TI RM57Lx ARM Cortex-R processor — use to control GPIO outputs for actuators or indicators | Digital Write | Embedded Coder Support Package for ARM Cortex-R Processors |

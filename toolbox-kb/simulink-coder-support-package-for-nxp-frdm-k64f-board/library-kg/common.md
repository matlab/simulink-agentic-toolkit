# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read analog voltage from ADC channels on NXP FRDM-K64F — use for sampling sensor signals in embedded applications | Analog Input | Simulink Coder Support Package for NXP FRDM-K64F Board |
| Read digital GPIO pin state on NXP FRDM-K64F — use for reading buttons, switches, or digital sensor inputs | Digital Read | Simulink Coder Support Package for NXP FRDM-K64F Board |
| Write digital GPIO pin state on NXP FRDM-K64F — use for controlling LEDs, relays, or digital outputs | Digital Write | Simulink Coder Support Package for NXP FRDM-K64F Board |
| Generate PWM signals on FRDM-K64F timer channels — use for motor control, LED dimming, or servo positioning | PWM Output | Simulink Coder Support Package for NXP FRDM-K64F Board |
| Receive data over UART on FRDM-K64F — use for reading data from serial-connected devices or sensors | Serial Receive | Simulink Coder Support Package for NXP FRDM-K64F Board |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Execute a subsystem as a Linux process task on an ARM Cortex-A processor — use to deploy algorithms as real-time Linux tasks on application processors | Linux Task | Embedded Coder Support Package for ARM Cortex-A Processors |
| Receive UDP datagrams on the ARM Cortex-A target — use for host-target communication over Ethernet during deployment | UDP Receive | Embedded Coder Support Package for ARM Cortex-A Processors |
| Send UDP datagrams from the ARM Cortex-A target — use for telemetry or parameter exchange with a host PC | UDP Send | Embedded Coder Support Package for ARM Cortex-A Processors |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Run inference on a LiteRT model within Simulink — use for deploying TensorFlow Lite models on edge devices or mobile targets | LiteRT | MATLAB Coder Support Package for PyTorch and LiteRT Models |
| Run inference on a PyTorch ExportedProgram within Simulink — use for integrating PyTorch-trained models into Simulink-based systems | PyTorch ExportedProgram | MATLAB Coder Support Package for PyTorch and LiteRT Models |

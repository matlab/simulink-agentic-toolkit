# Mechanical mechanisms

Use these blocks for mechanical mechanisms.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Gear Box | fl_lib/Mechanical/Mechanisms/Gear Box | R2023a+ | Use when modeling an ideal gear ratio between rotational and translational or two rotational shafts |
| Lever | fl_lib/Mechanical/Mechanisms/Lever | R2023a+ | Use when modeling a rigid lever that transforms translational force and displacement by arm ratio |
| Slider-Crank | fl_lib/Mechanical/Mechanisms/Slider-Crank | R2023a+ | Use when converting rotational motion to reciprocating translational motion via a crank mechanism |
| Wheel and Axle | fl_lib/Mechanical/Mechanisms/Wheel and Axle | R2023a+ | Use when converting between rotational and translational motion through a wheel rolling without slip |
| Rotational Multibody Interface | fl_lib/Mechanical/Multibody Interfaces/Rotational Multibody Interface | R2023a+ | Use when connecting a 1-D rotational Simscape network to a Simscape Multibody joint |
| Translational Multibody Interface | fl_lib/Mechanical/Multibody Interfaces/Translational Multibody Interface | R2023a+ | Use when connecting a 1-D translational Simscape network to a Simscape Multibody joint |
| Cam and Follower (AB-PB) | fl_lib/Mechanisms/Cam and Follower (AB-PB) | R2023a+ | Use when modeling a cam profile that converts rotational input to prescribed translational follower motion |
| Wheel and Axle (AB-PB) | fl_lib/Mechanisms/Wheel and Axle (AB-PB) | R2023a+ | Use when converting across-based rotational motion to position-based translational motion through a wheel |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Use when modeling energy storage in an electric field or filtering high-frequency signals in a circuit | Capacitor | Simscape |
| Use to establish a ground node as the zero-voltage reference in any electrical network | Electrical Reference | Simscape |
| Use when modeling energy storage in a magnetic field or smoothing current ripple in power supplies | Inductor | Simscape |
| Use when modeling ohmic losses, voltage division, or current limiting in any electrical circuit | Resistor | Simscape |
| Use when supplying a constant voltage such as a battery or regulated power rail | DC Voltage Source | Simscape |
| Use when modeling rotational kinetic energy storage due to mass moment of inertia of a spinning body | Inertia | Simscape |
| Use when modeling viscous friction that produces torque proportional to angular velocity difference | Rotational Damper | Simscape |
| Use when modeling translational kinetic energy storage due to a body with inertial mass | Mass | Simscape |
| Use when modeling a linear spring that produces force proportional to displacement difference | Translational Spring | Simscape |
| Use when summing two physical signals to combine contributions from multiple sources | PS Add | Simscape |
| Use when scaling a physical signal by a constant multiplier | PS Gain | Simscape |
| Use when modeling thermal energy storage in a body with specified heat capacity | Thermal Mass | Simscape |

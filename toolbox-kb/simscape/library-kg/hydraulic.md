# Hydraulic

Use these blocks for hydraulic.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Constant Area Hydraulic Orifice | fl_lib/Hydraulic/Hydraulic Elements/Constant Area Hydraulic Orifice | R2023a+ | The block models a sharp-edged constant-area orifice, flow rate through which is proportional to the pressure differential across the orifice. Connections A and B are conserving hydraulic ports associated with the orifice inlet and outlet, respectively. The block positive direction is from port A to port B. This means that the flow rate is positive if fluid flows from A to B, and the pressure differential is determined as p = p_A - p_B. |
| Constant Volume Hydraulic Chamber | fl_lib/Hydraulic/Hydraulic Elements/Constant Volume Hydraulic Chamber | R2023a+ | The block represents a fixed-volume chamber with rigid or flexible walls used in hydraulic valves, pumps, manifolds, pipes, hoses, and so on. Use this block in models where you have to account for fluid compressibility. The block has one hydraulic conserving port associated with the chamber inlet. The block positive direction is from its port to the reference point. This means that the flow rate is positive if it flows into the chamber. |
| Fluid Inertia | fl_lib/Hydraulic/Hydraulic Elements/Fluid Inertia | R2023a+ | The block models pressure differential caused by change in fluid velocity across a fluid passage of constant cross-sectional area. Connections A and B are hydraulic conserving ports. The block positive direction is from port A to port B. |
| Hydraulic Cap | fl_lib/Hydraulic/Hydraulic Elements/Hydraulic Cap | R2023a+ | This block represents a closed hydraulic circuit. No flow is permitted through this component. Connect it to hydraulic ports of other blocks that should not allow flow and optionally specify initial pressure. |
| Hydraulic Reference | fl_lib/Hydraulic/Hydraulic Elements/Hydraulic Reference | R2023a+ | This block represents a connection to atmosphere. It has one hydraulic conserving port. Connect to it hydraulic ports of other blocks that are considered directly connected to atmosphere. |
| Hydraulic Resistive Tube | fl_lib/Hydraulic/Hydraulic Elements/Hydraulic Resistive Tube | R2023a+ | This block models hydraulic pipelines with circular and noncircular cross sections and accounts for resistive property only. To account for local resistances such as bends, fittings, inlet and outlet losses, and so on, all the resistances are converted into their equivalent lengths, and then the total length of all the resistances is added to the pipe geometrical length. Connections A and B are hydraulic conserving ports. The block positive direction is from port A to port B. This means that the flow rate is positive if fluid flows from A to B, and the pressure loss is determined as p = p_A - p_B. |
| Infinite Hydraulic Resistance | fl_lib/Hydraulic/Hydraulic Elements/Infinite Hydraulic Resistance | R2023a+ | This block represents a break in an hydraulic network. There is no flow through the break. However, the fluid properties, specified by the Custom Hydraulic Fluid block connected to the circuit, are the same on both sides of the break. This block can optionally be used to assign a beginning value and priority to the difference in pressure of port A relative to port B. |
| Linear Hydraulic Resistance | fl_lib/Hydraulic/Hydraulic Elements/Linear Hydraulic Resistance | R2023a+ | This block represents a hydraulic resistance where pressure loss is directly proportional to flow rate. Connections A and B are conserving hydraulic ports associated with the block inlet and outlet, respectively. The block positive direction is from port A to port B. This means that the flow rate is positive if fluid flows from A to B, and the pressure loss is determined as p = p_A - p_B. |
| Variable Area Hydraulic Orifice | fl_lib/Hydraulic/Hydraulic Elements/Variable Area Hydraulic Orifice | R2023a+ | The block models a variable area orifice. The area of the orifice is expected to be computed outside the block and imported via the AR physical signal connection. The flow rate through the orifice is proportional to the orifice area and pressure differential across the orifice. Connections A and B are conserving hydraulic ports associated with the orifice inlet and outlet, respectively. Connection AR is a physical signal port through which an instantaneous value of the orifice area is provided. The block positive direction is from port A to port B. |
| Variable Hydraulic Chamber | fl_lib/Hydraulic/Hydraulic Elements/Variable Hydraulic Chamber | R2023a+ | The block models fluid compressibility in variable volume chambers. The instantaneous value of the chamber volume is provided via the physical signal port V. Note that this block takes into account only the flow rate caused by fluid compressibility and is intended to be connected in parallel with the block that simulates flow consumption due to volume change. Port A is a hydraulic conserving port associated with the chamber inlet. Port V is a physical signal port that corresponds to chamber volume. The block positive direction is from port A to the reference point. This means that the flow rate is positive if it flows into the chamber. |
| Hydraulic Flow Rate Sensor | fl_lib/Hydraulic/Hydraulic Sensors/Hydraulic Flow Rate Sensor | R2023a+ | The block measures the flow rate in a hydraulic network. There is no change in pressure across the sensor. Physical signal outputs Q and M report the liquid volumetric flow rate and mass flow rate, respectively, through the sensor. The positive flow direction is from port A to port B. |
| Hydraulic Pressure Sensor | fl_lib/Hydraulic/Hydraulic Sensors/Hydraulic Pressure Sensor | R2023a+ | The block represents an ideal hydraulic pressure sensor, that is, a device that converts hydraulic pressure differential measured between two points into a physical control signal proportional to the pressure. Connections A and B are conserving hydraulic ports and connection P is a physical signal port. The sensor is oriented from A to B and measured pressure is P = p_A - p_B. |
| Hydraulic Constant Flow Rate Source | fl_lib/Hydraulic/Hydraulic Sources/Hydraulic Constant Flow Rate Source | R2023a+ | The block represents an ideal source of hydraulic energy that is powerful enough to maintain specified flow rate at its outlet regardless of pressure differential across the source. The flow rate through the source is specified by the block parameter. Block connections T and P are the conserving hydraulic ports associated with the source inlet and outlet respectively. The block positive direction is from port T to port P. |
| Hydraulic Constant Pressure Source | fl_lib/Hydraulic/Hydraulic Sources/Hydraulic Constant Pressure Source | R2023a+ | The block represents an ideal source of hydraulic energy that is powerful enough to maintain specified pressure difference regardless of the flow rate through the source. The pressure difference between ports P and T is specified with the block parameter. Block connections T and P correspond to the source inlet and outlet ports respectively. The block positive direction is from port P to port T. |
| Hydraulic Flow Rate Source | fl_lib/Hydraulic/Hydraulic Sources/Hydraulic Flow Rate Source | R2023a+ | The block represents an ideal source of hydraulic energy that is powerful enough to maintain specified flow rate at its outlet regardless of the pressure differential across the source. Block connections T and P correspond to the hydraulic inlet and outlet ports, respectively, and connection S represents a physical signal port. The flow rate through the source is directly proportional to the control signal. The block positive direction is from port T to port P. |
| Hydraulic Pressure Source | fl_lib/Hydraulic/Hydraulic Sources/Hydraulic Pressure Source | R2023a+ | The block represents an ideal source of hydraulic energy that is powerful enough to maintain specified pressure at its outlet regardless of the flow rate consumed by the system. Block connections T and P correspond to the hydraulic inlet and outlet ports, respectively, and connection S represents a physical signal port. The pressure differential across the source is directly proportional to the control signal. The block positive direction is from port P to port T. |
| Custom Hydraulic Fluid | fl_lib/Hydraulic/Hydraulic Utilities/Custom Hydraulic Fluid | R2023a+ | The block assigns fluid properties for all components assembled in a particular loop. The loop detection is performed automatically and the block is considered as part of the loop if it is hydraulically connected to at least one of the loop components. If no Hydraulic Fluid block is connected to the loop, the default properties of the Custom Hydraulic Fluid block are assigned. |
| Interface (H-IL) | fl_lib/Hydraulic/Hydraulic Utilities/Interface (H-IL) | R2023a+ | This block represents a flow connection between Hydraulic and Isothermal liquid networks. Pressure and mass flow rates are equal at the interface. Fluid properties of each fluid network are not shared across the interface. |

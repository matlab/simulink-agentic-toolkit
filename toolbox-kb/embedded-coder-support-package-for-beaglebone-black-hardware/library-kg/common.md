# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read analog voltage from ADC inputs on BeagleBone Black — use for sampling sensor signals like temperature, light, or force | Analog Input | Embedded Coder Support Package for BeagleBone Black Hardware |
| Read digital GPIO pin state on BeagleBone Black — use for reading buttons, switches, or digital sensor inputs | GPIO Read | Embedded Coder Support Package for BeagleBone Black Hardware |
| Write digital GPIO pin state on BeagleBone Black — use for controlling LEDs, relays, or digital outputs | GPIO Write | Embedded Coder Support Package for BeagleBone Black Hardware |
| Generate PWM output on BeagleBone Black — use for motor speed control, servo positioning, or LED brightness dimming | PWM | Embedded Coder Support Package for BeagleBone Black Hardware |

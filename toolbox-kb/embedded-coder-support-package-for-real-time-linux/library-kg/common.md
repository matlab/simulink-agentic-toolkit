# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Receive CAN messages via SocketCAN on real-time Linux — use for reading vehicle bus data on Linux-based embedded targets | CAN Receive block | Embedded Coder Support Package for Real-Time Linux |
| Transmit CAN messages via SocketCAN on real-time Linux — use for sending vehicle bus commands from Linux-based embedded targets | CAN Transmit block | Embedded Coder Support Package for Real-Time Linux |

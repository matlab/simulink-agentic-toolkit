# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Configure serial port parameters like baud rate and parity — use for setting up RS-232/RS-485 communication before send/receive operations | Serial Configuration | Instrument Control Toolbox |
| Receive data from a serial port — use for reading measurement data or responses from serial-connected instruments or microcontrollers | Serial Receive | Instrument Control Toolbox |
| Send data through a serial port — use for transmitting commands or data to serial-connected instruments or microcontrollers | Serial Send | Instrument Control Toolbox |
| Receive data over a TCP/IP network connection — use for acquiring data from networked instruments, remote systems, or lab equipment | TCP/IP Receive | Instrument Control Toolbox |
| Send data over a TCP/IP network connection — use for transmitting commands or data to networked instruments or remote systems | TCP/IP Send | Instrument Control Toolbox |

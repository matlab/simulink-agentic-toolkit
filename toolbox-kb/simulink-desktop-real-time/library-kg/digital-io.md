# Digital io

Use these blocks for digital io.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Servo Output | sldrtlib/Servo Output | R2023a+ | Generate servo control signals via real-time hardware — use for driving RC servos or positioning actuators from desktop real-time models |
| Counter Input | sldrtlib/Counter Input | R2023a+ | Read hardware counter values in real time — use for measuring encoder counts, pulse frequencies, or event timing |
| Digital Input | sldrtlib/Digital Input | R2023a+ | Read digital channels from DAQ hardware in real time — use for acquiring switch states or digital sensor signals |
| Digital Output | sldrtlib/Digital Output | R2023a+ | Write digital channels to DAQ hardware in real time — use for controlling relays, indicators, or digital actuators |
| Encoder Input | sldrtlib/Encoder Input | R2023a+ | Read quadrature encoder position in real time — use for measuring motor shaft angle or linear position with hardware decoding |
| Frequency Output | sldrtlib/Frequency Output | R2023a+ | Generate a frequency signal via DAQ hardware — use for producing clock outputs or variable-frequency drive signals |

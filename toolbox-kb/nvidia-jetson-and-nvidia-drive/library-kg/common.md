# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read GPIO pin state on NVIDIA Jetson — use for reading digital input signals from buttons, switches, or external sensors | GPIO Read | NVIDIA Jetson and NVIDIA DRIVE |
| Write GPIO pin state on NVIDIA Jetson — use for controlling LEDs, relays, or other digital output peripherals | GPIO Write | NVIDIA Jetson and NVIDIA DRIVE |
| Access communication interfaces on NVIDIA Jetson/DRIVE — use for I2C, SPI, UART, or CAN bus communication with external devices | Communication | NVIDIA Jetson and NVIDIA DRIVE |

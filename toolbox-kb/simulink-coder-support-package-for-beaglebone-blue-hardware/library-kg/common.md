# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Access motor and servo actuator peripherals on BeagleBone Blue — use for driving DC motors, servos, or ESCs from generated code | Actuators | Simulink Coder Support Package for BeagleBone Blue Hardware |
| Access communication peripherals on BeagleBone Blue — use for I2C, SPI, UART, or CAN interfaces on the BeagleBone Blue | Communication | Simulink Coder Support Package for BeagleBone Blue Hardware |
| Access onboard sensors on BeagleBone Blue — use for reading IMU, barometer, or encoder data from the BeagleBone Blue | Sensors | Simulink Coder Support Package for BeagleBone Blue Hardware |

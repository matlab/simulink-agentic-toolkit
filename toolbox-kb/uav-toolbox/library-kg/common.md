# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Follow a sequence of 3D waypoints — use for basic point-to-point UAV navigation with smooth transitions between waypoints | Waypoint Follower | UAV Toolbox |
| Spawn a 3D UAV in the Unreal simulation scene — use for visualizing multirotor or fixed-wing UAV flight in 3D | Simulation 3D UAV Vehicle | UAV Toolbox |
| Configure the 3D simulation environment for UAV scenarios — use for selecting terrain, weather, and rendering settings | Simulation 3D Scene Configuration | UAV Toolbox |
| Configure a UAV scenario with platforms and obstacles — use for defining the simulation environment including terrain and no-fly zones | UAV Scenario Configuration | UAV Toolbox |
| Simulate GPS receiver for UAV navigation — use for generating position and velocity with configurable accuracy and outages | GPS | UAV Toolbox |
| Simulate integrated navigation system for UAV — use for generating fused pose data with realistic error characteristics | INS | UAV Toolbox |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Model the AD9361 receiver chain — use for simulating wideband RF receive path with gain, filtering, and ADC effects | ad9361_rx | RF Blockset Models for Analog Devices RF Transceivers |
| Model the AD9361 transmitter chain — use for simulating RF transmit path with DAC, filtering, and PA nonlinearity | ad9361_tx | RF Blockset Models for Analog Devices RF Transceivers |
| Model the AD9371 observation receiver — use for simulating the ORx path used in DPD feedback | ad9371_orx | RF Blockset Models for Analog Devices RF Transceivers |
| Model the AD9371 receiver chain — use for simulating wideband receive with digital downconversion | ad9371_rx | RF Blockset Models for Analog Devices RF Transceivers |
| Model the AD9371 transmitter chain — use for simulating wideband transmit with digital predistortion support | ad9371_tx | RF Blockset Models for Analog Devices RF Transceivers |

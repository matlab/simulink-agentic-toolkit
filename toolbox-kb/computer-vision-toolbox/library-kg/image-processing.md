# Image processing

Use these blocks for image processing.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Analysis & Enhancement | visionlib/Analysis & Enhancement | R2023a+ | Analyze and enhance images with edge detection, histogram equalization, contrast adjustment, and blob analysis — use for preprocessing steps that improve feature visibility before detection or recognition |
| Filtering | visionlib/Filtering | R2023a+ | Apply spatial filters (median, Gaussian, bilateral, custom kernels) to images — use for noise reduction, smoothing, or sharpening as part of an image processing pipeline |
| Geometric Transformations | visionlib/Geometric Transformations | R2023a+ | Apply geometric operations (resize, rotate, warp, crop, affine/projective transforms) to images — use for image registration, perspective correction, or preparing images for fixed-size network inputs |
| Morphological Operations | visionlib/Morphological Operations | R2023a+ | Apply morphological operations (erode, dilate, open, close, top-hat) to binary and grayscale images — use for shape-based filtering, noise removal from binary masks, or object segmentation refinement |

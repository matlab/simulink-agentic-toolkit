# Image analysis

Use these blocks for image analysis.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Statistics | visionlib/Statistics | R2023a+ | Compute image statistics (mean, variance, histogram, min/max, projection) — use for image quality metrics, automatic thresholding, or feature computation in classification pipelines |
| Transforms | visionlib/Transforms | R2023a+ | Apply frequency-domain and spatial transforms (FFT, DCT, Radon, Hough) to images — use for frequency analysis, feature extraction, or line/circle detection in structured scenes |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Define rigid body geometry, inertia, and visual properties — use for creating the physical bodies that make up a multibody mechanism | Body Elements | Multibody |
| Apply external forces and torques to bodies — use for modeling gravity, springs, dampers, actuators, or any applied load in a multibody system | Forces and Torques | Multibody |
| Define coordinate frames and spatial transformations — use for positioning, orienting, and relating reference frames within a multibody assembly | Frames and Transforms | Multibody |
| Connect bodies with degrees of freedom — use for revolute, prismatic, spherical, or other articulated connections in a multibody mechanism | Joints | Multibody |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Configure multi-core task scheduling on AURIX TC4x — use for assigning and managing real-time tasks across multiple CPU cores | Task Manager | Embedded Coder Support Package for Infineon AURIX TC4x |
| Read shared data between CPU cores on AURIX TC4x — use for receiving variables published by tasks running on other cores | Interprocess Data Read | Embedded Coder Support Package for Infineon AURIX TC4x |
| Write shared data between CPU cores on AURIX TC4x — use for publishing variables to tasks running on other cores | Interprocess Data Write | Embedded Coder Support Package for Infineon AURIX TC4x |
| Test bench ADC interface for AURIX TC4x — use for injecting analog sensor signals into processor-in-the-loop or SIL test environments | ADC Interface | Embedded Coder Support Package for Infineon AURIX TC4x |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Control EV3 motors with speed or position commands — use for driving wheels, arms, or other actuated mechanisms | Motor | Simulink Support Package for LEGO MINDSTORMS EV3 Hardware |
| Read color or light intensity from the EV3 color sensor — use for line following, color sorting, or ambient light detection | Color Sensor | Simulink Support Package for LEGO MINDSTORMS EV3 Hardware |
| Read motor encoder position and speed — use for closed-loop motor control or odometry in navigation tasks | Encoder | Simulink Support Package for LEGO MINDSTORMS EV3 Hardware |
| Read angular rate and heading from the EV3 gyro sensor — use for rotation measurement, balancing, or heading control | Gyro Sensor | Simulink Support Package for LEGO MINDSTORMS EV3 Hardware |
| Measure distance using the EV3 ultrasonic sensor — use for obstacle detection and distance measurement in navigation | Ultrasonic Sensor | Simulink Support Package for LEGO MINDSTORMS EV3 Hardware |

# Sensors

Use these blocks for sensors.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| NXT Sensors | legoev3lib/NXT Sensors | R2023a+ | Interface with legacy NXT sensors on EV3 — use for reading older NXT-compatible sensors connected to EV3 ports |
| Battery | legoev3lib/Battery | R2023a+ | Read EV3 battery voltage level — use for monitoring remaining battery life and triggering low-power behaviors |
| Color Sensor | legoev3lib/Color Sensor | R2023a+ | Read color or light intensity from the EV3 color sensor — use for line following, color sorting, or ambient light detection |
| Gyro Sensor | legoev3lib/Gyro Sensor | R2023a+ | Read angular rate and heading from the EV3 gyro sensor — use for rotation measurement, balancing, or heading control |
| Infrared Sensor | legoev3lib/Infrared Sensor | R2023a+ | Read proximity or IR beacon data from the EV3 infrared sensor — use for obstacle detection or remote control reception |
| Pixy2 Vision Sensor | legoev3lib/Pixy2 Vision Sensor | R2023a+ | Read object detection data from a Pixy2 camera on EV3 — use for color blob tracking or line following with vision |
| Timer | legoev3lib/Timer | R2023a+ | Read elapsed time on EV3 — use for timing operations, creating delays, or measuring event durations |
| Touch Sensor | legoev3lib/Touch Sensor | R2023a+ | Read the EV3 touch sensor press state — use for detecting physical contact, bumper hits, or limit switches |
| Ultrasonic Sensor | legoev3lib/Ultrasonic Sensor | R2023a+ | Measure distance using the EV3 ultrasonic sensor — use for obstacle detection and distance measurement in navigation |

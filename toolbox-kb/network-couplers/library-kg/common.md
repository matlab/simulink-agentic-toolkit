# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Couple two electrical networks via a virtual capacitor — use for partitioning large electrical circuits into separately-solved networks at a capacitive interface | Network Coupler (Capacitor) | Network Couplers |
| Couple two mechanical rotational networks via a flexible shaft — use for partitioning driveline models at a compliant shaft element | Network Coupler (Flexible Shaft) | Network Couplers |
| Couple two thermal networks via a thermal mass — use for partitioning thermal systems at a heat capacity element | Network Coupler (Thermal Mass) | Network Couplers |

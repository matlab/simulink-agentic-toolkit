# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Use when you need to detect anomalies or outliers in multivariate data using an isolation forest that identifies rare observations by random partitioning | Isolation Forest Anomaly Detector | Statistics and Machine Learning Toolbox |
| Use when you need robust classification by aggregating predictions from multiple weak learners such as bagged trees or boosted ensembles | ClassificationEnsemble Predict | Statistics and Machine Learning Toolbox |
| Use when you need to classify data using a pretrained support vector machine with kernel-based margin maximization | ClassificationSVM Predict | Statistics and Machine Learning Toolbox |
| Use when you need interpretable classification using a pretrained decision tree with explicit splitting rules | ClassificationTree Predict | Statistics and Machine Learning Toolbox |
| Use when you need to find the k-nearest neighbors of query points for similarity search, classification preprocessing, or density estimation | KNN Search | Statistics and Machine Learning Toolbox |
| Use when you need to update a linear classifier online using SGD as new labeled data streams in | IncrementalClassificationLinear Fit | Statistics and Machine Learning Toolbox |
| Use when you need to monitor streaming model predictions for concept drift and trigger retraining when data distribution shifts | Detect Drift | Statistics and Machine Learning Toolbox |
| Use when you need to update a linear regression model online using SGD with streaming data | IncrementalRegressionLinear Fit | Statistics and Machine Learning Toolbox |
| Use when you need to run predictions from a pretrained scikit-learn Python model within a Simulink simulation | Scikit-learn Model Predict | Statistics and Machine Learning Toolbox |
| Use when you need robust continuous value prediction from a pretrained ensemble of regression trees or boosted models | RegressionEnsemble Predict | Statistics and Machine Learning Toolbox |
| Use when you need regression using a pretrained support vector machine with epsilon-insensitive loss | RegressionSVM Predict | Statistics and Machine Learning Toolbox |
| Use when you need interpretable regression using a pretrained decision tree with piecewise constant predictions | RegressionTree Predict | Statistics and Machine Learning Toolbox |

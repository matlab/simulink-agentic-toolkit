# Simulink Block Category

* [Board io](board-io.md) - Physical board I/O blocks for switches, buttons, LEDs, and GPIO pins (5 blocks)
* [Fpga connectivity](fpga-connectivity.md) - AXI4-Stream and bus connectivity between FPGA and processor domains (6 blocks)
* [Interprocess](interprocess.md) - Shared data channels for communication between processor tasks at different rates (3 blocks)
* [Io data](io-data.md) - I/O data injection and capture for testbench-driven SoC verification (8 blocks)
* [Memory interfaces](memory-interfaces.md) - Shared memory, DMA, registers, and interrupt channels between FPGA and processor (8 blocks)
* [Peripherals](peripherals.md) - Peripheral device interface models for ADC, audio, video, PWM, and digital I/O (7 blocks)
* [Processor io](processor-io.md) - Processor-side read/write blocks for accessing hardware peripherals and network (24 blocks)
* [Task scheduling](task-scheduling.md) - Task management, scheduling, triggering, and interrupt-driven execution (5 blocks)
* [Test infrastructure](test-infrastructure.md) - Testbench source and sink blocks for verifying hardware interfaces in simulation (6 blocks)
* [Uncategorized](uncategorized.md) - Blocks for Uncategorized (40 blocks)

# Peripherals

Use these blocks for peripherals.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| ADC Interface | peripheralslib/ADC Interface | R2023a+ | Model an analog-to-digital converter peripheral on the SoC development board |
| Audio Capture Interface | peripheralslib/Audio Capture Interface | R2023a+ | Model an audio input peripheral for capturing audio samples on the SoC |
| Audio Playback Interface | peripheralslib/Audio Playback Interface | R2023a+ | Model an audio output peripheral for playing audio samples on the SoC |
| Digital IO Interface | peripheralslib/Digital IO Interface | R2023a+ | Model digital I/O peripheral pins on the SoC development board |
| PWM Interface | peripheralslib/PWM Interface | R2023a+ | Model a PWM output peripheral on the SoC for motor or LED control |
| Video Capture Interface | peripheralslib/Video Capture Interface | R2023a+ | Model a camera or video input peripheral on the SoC development board |
| Video Display Interface | peripheralslib/Video Display Interface | R2023a+ | Model a video output peripheral for driving a display from the SoC |

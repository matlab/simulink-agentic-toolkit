# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| HDL-optimized DSP filters with streaming interfaces — use for hardware-targeted filtering when DSP System Toolbox algorithms must run on FPGA | Filtering | DSP System Toolbox HDL Support |
| HDL-optimized signal processing operations — use for time-domain signal manipulation in hardware-targeted designs | Signal Operations | DSP System Toolbox HDL Support |

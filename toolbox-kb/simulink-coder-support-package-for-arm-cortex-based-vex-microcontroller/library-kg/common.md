# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Drive a VEX DC motor — use for commanding motor speed on VEX Cortex motor ports | DC Motor | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |
| Read VEX gamepad joystick axis — use for analog joystick input from the VEX controller | Gamepad Joystick | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |
| Read VEX gyroscope — use for measuring robot heading and turn rate | Gyroscope | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |
| Read VEX optical shaft encoder — use for measuring wheel rotation and distance | Optical Shaft Encoder | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |
| Read VEX ultrasonic distance sensor — use for detecting obstacles and measuring range | Ultrasonic Sensor | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |
| Map joystick to arcade drive — use for converting single-stick input to differential motor commands | Arcade Module | Simulink Coder Support Package for ARM Cortex-based VEX Microcontroller |

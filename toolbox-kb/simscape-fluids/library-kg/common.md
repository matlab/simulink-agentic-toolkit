# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Use to model heat transfer between two thermal liquid streams such as oil-to-coolant or water-to-glycol loops | Heat Exchanger (TL-TL) | Simscape Fluids |
| Use to model a double-acting hydraulic cylinder driven by isothermal liquid pressure on both piston sides | Double-Acting Actuator (IL) | Simscape Fluids |
| Use to model a straight segment of isothermal liquid pipe with distributed friction and fluid inertia | Pipe (IL) | Simscape Fluids |
| Use to model a positive-displacement hydraulic pump with fixed volumetric output per revolution | Fixed-Displacement Pump (IL) | Simscape Fluids |
| Use to model a gas-charged hydraulic accumulator that stores energy and damps pressure pulsations | Gas-Charged Accumulator (IL) | Simscape Fluids |
| Use to model a hydraulic reservoir or open tank that sets reference pressure in an isothermal liquid circuit | Tank (IL) | Simscape Fluids |
| Use to control a double-acting hydraulic actuator with extend, retract, and center-neutral positions | 4-Way 3-Position Directional Valve (IL) | Simscape Fluids |
| Use to allow isothermal liquid flow in one direction only, preventing backflow in hydraulic circuits | Check Valve (IL) | Simscape Fluids |
| Use to model a fixed flow restriction in an isothermal liquid line for metering or pressure drop control | Orifice (IL) | Simscape Fluids |
| Use to protect a hydraulic circuit from overpressure by diverting excess flow when pressure exceeds the set point | Pressure Relief Valve (IL) | Simscape Fluids |
| Use to model a straight thermal liquid pipe segment with friction, inertia, and wall heat transfer | Pipe (TL) | Simscape Fluids |
| Use to model a centrifugal pump in a thermal liquid system with head-flow curves and heat generation | Centrifugal Pump (TL) | Simscape Fluids |

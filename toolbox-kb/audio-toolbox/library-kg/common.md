# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Apply compression, expansion, limiting, or gating to control audio signal amplitude — use to prevent clipping, reduce dynamic range for broadcast, or shape transient response | Dynamic Range Control | Audio Toolbox |
| Extract audio features like MFCCs, spectral centroid, pitch, or zero-crossing rate — use for audio analysis, speech recognition preprocessing, or music information retrieval | Features | Audio Toolbox |
| Design and apply audio filters including parametric EQ, crossovers, shelving, and octave-band filters — use for frequency-selective processing in audio systems | Filters | Audio Toolbox |
| Output audio to speakers, files, or audio devices — use as the final stage in an audio processing pipeline to play back or record processed signals | Sinks | Audio Toolbox |
| Generate or acquire audio from microphones, files, oscillators, or noise generators — use as input to audio processing pipelines for real-time capture or offline analysis | Sources | Audio Toolbox |

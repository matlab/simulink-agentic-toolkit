# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read data from FPGA fabric via AXI4 interface on Intel SoC — use for processor-to-FPGA data transfer in Intel Cyclone/Arria SoC designs | AXI4 Read | Embedded Coder Support Package for Intel SoC Devices |
| Write data to FPGA fabric via AXI4 interface on Intel SoC — use for processor-to-FPGA command or data passing in Intel SoC designs | AXI4 Write | Embedded Coder Support Package for Intel SoC Devices |
| Configure a Linux task for execution on Intel SoC ARM core — use for scheduling generated code as a Linux process on the HPS | Linux Task | Embedded Coder Support Package for Intel SoC Devices |

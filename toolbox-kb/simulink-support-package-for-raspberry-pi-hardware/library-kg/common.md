# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Sublibrary of Raspberry Pi serial/bus communication blocks (I2C, SPI, UART, CAN) — open to pick a specific interface block. | Communication | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of Raspberry Pi network communication blocks (TCP/IP, UDP) — open to pick a specific networking block. | Network  | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of Raspberry Pi sensor blocks — open to pick a specific sensor input block. | Sensors | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of Raspberry Pi audio and video I/O blocks (ALSA audio, camera capture, display) — open to pick a specific media block. | Audio and Video | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of core Raspberry Pi hardware blocks (digital I/O, LED, GPIO) — open to pick a specific device block. | Basic | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of Raspberry Pi IoT connectivity blocks (MQTT, ThingSpeak) — open to pick a specific cloud/messaging block. | Internet Of Things | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of blocks for the Sense HAT add-on board (LED matrix, joystick, environmental sensors). | Sense HAT | Simulink Support Package for Raspberry Pi Hardware |
| Sublibrary of Raspberry Pi helper and utility blocks. | Utilities | Simulink Support Package for Raspberry Pi Hardware |

# Convolution layers

Use these blocks for convolution layers.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Convolution 1D Layer | dlconvfclib/Convolution 1D Layer | R2024b+ | Apply learned 1-D convolutional filters to sequential data — use for temporal pattern detection in time-series, audio, or sensor signal classification networks |
| Convolution 2D Layer | dlconvfclib/Convolution 2D Layer | R2024b+ | Apply learned 2-D convolutional filters to image or spatial data — use as the core feature extraction layer in image classification, detection, and segmentation networks |
| Convolution 3D Layer | dlconvfclib/Convolution 3D Layer | R2024b+ | Apply learned 3-D convolutional filters to volumetric or video data — use for spatiotemporal feature extraction in video analysis or 3-D medical imaging networks |
| Fully Connected Layer | dlconvfclib/Fully Connected Layer | R2024b+ | Apply a learned linear transformation (matrix multiply plus bias) — use as a dense layer for classification heads or regression outputs after feature extraction |

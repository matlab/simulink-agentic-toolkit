# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Spawn a 3D vehicle that follows terrain elevation — use for realistic vehicle visualization on roads with grade changes | Simulation 3D Vehicle with Ground Following | Simulink 3D Animation |
| Configure the 3D simulation environment — use for selecting scene, weather, lighting, and rendering options for the virtual world | Simulation 3D Scene Configuration | Simulink 3D Animation |
| Attach a virtual camera to capture images in the 3D scene — use for generating synthetic camera data for perception testing | Simulation 3D Camera | Simulink 3D Animation |
| Attach a virtual lidar sensor in the 3D scene — use for generating synthetic point cloud data for perception algorithm development | Simulation 3D Lidar | Simulink 3D Animation |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Tank-style differential drive — use for commanding left/right motors from forward and turn inputs on V5 | Differential (Tank) Drive | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Command V5 Smart Motor — use for setting velocity, position, or torque targets on V5 Smart Motors | Smart Motor Write | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Read V5 gamepad joystick — use for analog stick input from V5 controller | Gamepad Joystick | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Read V5 Distance Sensor — use for measuring range to objects with time-of-flight | Distance Sensor | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Read V5 Inertial Sensor — use for measuring heading, pitch, roll, and acceleration | Inertial Sensor | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Read V5 Smart Motor state — use for getting position, velocity, current, and temperature | Smart Motor Read | Simulink Coder Support Package for VEX EDR V5 Robot Brain |
| Read V5 GPS Sensor — use for absolute field position and heading measurement | V5 GPS Sensor | Simulink Coder Support Package for VEX EDR V5 Robot Brain |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Model an open differential — use for simulating equal-torque split between driven wheels | Open Differential | Powertrain Blockset |
| Complete mapped gasoline engine system — use for fast simulation of gasoline powertrain with controller | Mapped SI Engine | Powertrain Blockset |
| Lookup-based motor model — use for fast motor simulation from efficiency and torque maps | Mapped Motor | Powertrain Blockset |
| Model hydrodynamic torque converter — use for simulating fluid coupling between engine and automatic transmission | Torque Converter | Powertrain Blockset |
| Single-DOF vehicle body — use for basic vehicle speed simulation with road load | Vehicle Body 1DOF Longitudinal | Powertrain Blockset |
| Provide standard drive cycle profiles — use for feeding velocity targets from regulatory or custom drive cycles | Drive Cycle Source | Powertrain Blockset |
| Driver model for speed tracking — use for simulating accelerator and brake pedal inputs to follow a drive cycle | Longitudinal Driver | Powertrain Blockset |

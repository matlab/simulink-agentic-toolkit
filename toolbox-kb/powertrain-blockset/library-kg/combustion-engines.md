# Combustion engines

Use these blocks for combustion engines.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Reduced Lundell Alternator | autolibalternator/Reduced Lundell Alternator | R2023a+ | Implements a reduced Lundell (claw-pole) alternator and voltage regulator. The back-EMF is proportional to the input speed and field current. The machine operates as a torque source to the combustion engine. |
| Bidirectional DC-DC | autolibdcdc/Bidirectional DC-DC | R2023a+ | Implements a DC to DC converter supporting bidirectional boost and buck operation. Specify the DC to DC transient response, power limit, and losses. Output voltage tracks the voltage command unless the DC to DC converter is power limiting. Specify electrical losses using measured losses or measured efficiency. |
| Datasheet Battery | autolibdatasheetbattery/Datasheet Battery | R2023a+ | Implements a model for a lithium ion, lithium polymer, or lead acid battery based off of discharge characteristics taken at different temperatures. The model can be parameterized using a typical battery datasheet or through experimental measurement. |
| Equivalent Circuit Battery | autolibrcnetworksystem/Equivalent Circuit Battery | R2023a+ | Implements a resistor-capacitor (RC) circuit battery that you can parameterize using equivalent circuit modeling (ECM). To simulate the state-of-charge (SOC) and terminal voltage, the block uses load current and internal core temperature. Calculates the combined network battery voltage using lookup tables that are functions of the SOC and battery temperature. Use the Estimation Equivalent Circuit Battery block to help create the lookup tables. |
| Estimation Equivalent Circuit Battery | autolibrcnetworksystem/Estimation Equivalent Circuit Battery | R2023a+ | Implements a resistor-capacitor (RC) circuit battery model that determines the combined voltage of a network battery using parameter lookup tables that are functions of the state-of-charge (SOC). Recommend using the block for estimating battery voltage and SOC, not in system-level models. |
| Starter | autolibstarter/Starter | R2023a+ | Implements an automotive starter as a separately excited DC motor permanent magnet DC motor, or series connection DC motor. The motor operates as a torque source to the combustion engine. |
| Boost Drive Shaft | autolibboost/Boost Drive Shaft | R2023a+ | Implements a rotating shaft connected to engine boost components. Uses compressor, turbine, and external torques to calculate the drive shaft speed. Specify one of the following configurations: - Turbocharger: Connect compressor to turbine (external torque optional) - Compressor only: Connect to compressor and provide external torque - Turbine only: Connect to turbine and provide external load torque |
| Compressor | autolibboost/Compressor | R2023a+ | Implements a turbocharger or supercharger compressor. Connects to inlet volume, outlet volume, and boost drive shaft. Determines mass and heat flow rates between the volumes and required shaft torque. |
| Turbine | autolibboost/Turbine | R2023a+ | Implements a fixed or variable geometry turbine (exhaust side of turbocharger) with a wastegate. Connects to inlet volume, outlet volume, and boost drive shaft. Determines mass and heat flow rates between the volumes and output shaft torque. |
| Mapped Core Engine | autolibcoreeng/Mapped Core Engine | R2023a+ | Model core engine torque, fuel, and exhaust from lookup maps — use as the map-based heart of a combustion-engine model. |
| CI Core Engine | autolibcoreeng/CI Core Engine | R2023a+ | Implements a compression-ignition (CI) engine from intake to exhaust port. Use the block for hardware-in-the-loop (HIL) engine control design, or vehicle-level fuel economy and performance simulations. The CI Core Engine block calculates: - Brake torque, using either the torque structure or simple torque model - Fuel flow - Air mass flow, including exhaust gas recirculation (EGR), using a speed-density model - Air-fuel ratio (AFR) - Exhaust temperature and exhaust mass flow rate |
| SI Core Engine | autolibcoreeng/SI Core Engine | R2023a+ | Implements a spark-ignition (SI) engine from intake to exhaust port. Use the block in larger vehicle models, hardware-in-the-loop (HIL) engine control design, or vehicle-level fuel economy and performance simulations. The SI Core Engine block calculates: - Brake torque, using either the torque structure or simple torque model - Fuel flow - Air mass flow, using either the speed-density or dual-independent cam phasing models - Air-fuel ratio (AFR) - Exhaust temperature and exhaust mass flow rate |
| Control Volume System | autolibfundflw/Control Volume System | R2023a+ | Implements a constant volume open thermodynamic system with heat transfer. Uses conservation of mass and energy, assuming an ideal gas, to determine the pressure and temperature. |
| Flow Boundary | autolibfundflw/Flow Boundary | R2023a+ | Implements flow boundary conditions. Set pressure and temperature as constants or external inputs. |
| Flow Restriction | autolibfundflw/Flow Restriction | R2023a+ | Implements isentropic ideal gas flow through an orifice. Uses conservation of mass and energy to determine the mass and heat flow rates. Flow velocity is limited by the local acoustic velocity (choked flow). You can specify a constant, external input, or throttle body geometry orifice area model. |
| Heat Exchanger | autolibfundflw/Heat Exchanger | R2023a+ | Implements heat exchanger (e.g. intercooler or EGR cooler). Inlet connects to an engine flow component (flow restriction, compressor, turbine, or engine) and outlet connects to a volume (control volume or environment). Model determines heat transfer rate and downstream temperature based on the upstream temperature, effectiveness, and temperature of the cooling medium. Model assumes no pressure drop. Pressure losses can be modeled by the connected flow component. |
| CI Controller | autolibengctrlr/CI Controller | R2023a+ | Implements a compression-ignition (CI) controller that uses the driver torque request to calculate the open-loop commands for injector pulse-width, VGT rack position, and EGR valve area percent required to meet the driver demand. The CI Core Engine block requires the open-loop control commands from the CI Controller block. The block has two subsystems: - Controller: Determines the open-loop CI engine actuator commands based on the torque request and measured engine speed. - Estimator: Determines the torque, estimated air mass flow, exhaust gas recirculation mass flow, exhaust back pressure, and exhaust gas temperature from intake manifold gas pressure, intake manifold gas temperature, engine speed, exhaust gas recirculation valve area percent, variable geometry turbocharger rack position, and variable geometry turbocharger speed. You can specify the torque estimation model. |
| SI Controller | autolibengctrlr/SI Controller | R2023a+ | Implements a spark-ignition (SI) controller that uses the driver torque request in conjunction with measured engine speed to calculate the open-loop air, fuel, spark, and cam-phaser actuator commands required to meet the driver torque demand. The SI Core Engine block requires the actuator commands from the SI Controller block outputs. The block has two subsystems: - Controller: Determines the open-loop commands based on the commanded torque, measured engine speed, and estimated cylinder air mass. - Estimator: Determines the estimated air mass flow, torque, and exhaust gas temperature. You can specify the air mass flow and torque estimation models. |
| Mapped CI Engine | autolibenginesystems/Mapped CI Engine | R2023a+ | Model a compression-ignition (diesel) engine from lookup maps — use for map-based diesel powertrain simulation. |
| Mapped SI Engine | autolibenginesystems/Mapped SI Engine | R2023a+ | Model a spark-ignition (gasoline) engine from lookup maps — use for map-based gasoline powertrain simulation. |
| Simple Engine | autolibenginesystems/Simple Engine | R2023a+ | Model an engine with a simple torque-speed characteristic — use for lightweight powertrain studies without detailed maps. |
| IM Controller | autolibmotorctrlr/IM Controller | R2023a+ | Implements an internal torque-based, field-oriented controller for an induction motor (IM) with an optional outer-loop speed controller. The torque control implements a strategy for weakening the magnetic flux. |
| Interior PM Controller | autolibmotorctrlr/Interior PM Controller | R2023a+ | Implements a torque-based, field-oriented controller for an internal permanent magnet synchronous machine (PMSM) with an optional outer-loop speed controller. The torque control implements strategies for maximizing the torque per amp (MTPA) and weakening the magnetic flux. |
| Surface Mount PM Controller | autolibmotorctrlr/Surface Mount PM Controller | R2023a+ | Implements a torque-based, field-oriented controller for an surface mount permanent magnet synchronous motor (PMSM) with an optional outer-loop speed controller. The torque control utilizes quadrature current and does not weaken the magnetic flux. |
| Equivalent Consumption Minimization Strategy | autolibhevctrlr/Equivalent Consumption Minimization Strategy | R2023a+ | Implements an equivalent consumption minimization strategy (ECMS) for hybrid electric vehicle control. ECMS optimizes the torque split between the engine and motor to minimize the energy consumption while maintaining the battery state of charge (SOC). Configure the block for different motor locations, adaptive or non-adaptive control, and gear optimization. |
| Torque Converter | autolibtrqconv/Torque Converter | R2023a+ | Implements a three-part torque converter consisting of an impeller, turbine, and stator with an optional clutch lock-up capability. You can specify the torque converter characteristics and clutch lock-up configurations. |
| AMT Controller | autolibtranscontrols/AMT Controller | R2023a+ | Automated manual transmission (AMT) controller, which generates an open loop clutch command based on a requested gear number. |
| CVT Controller | autolibtranscontrols/CVT Controller | R2023a+ | Implements a pushbelt continuously variable transmission (CVT) controller. The block uses standard pulley and geometric equations to calculate primary and secondary variator positions. |
| DCT Controller | autolibtranscontrols/DCT Controller | R2023a+ | Dual Clutch Transmission (DCT) controller, which generates open loop clutch commands based on a requested gear number. |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| HDL-optimized image analysis and enhancement operations — use for histogram equalization, edge detection, or contrast adjustment in FPGA vision pipelines | Analysis & Enhancement | Vision HDL Toolbox |
| HDL-optimized color space and data type conversions — use for RGB-to-grayscale, YCbCr conversion, or pixel format changes in FPGA video processing | Conversions | Vision HDL Toolbox |
| HDL-optimized spatial filtering operations — use for 2D FIR filters, median filters, or custom kernel convolutions in FPGA image processing | Filtering | Vision HDL Toolbox |
| HDL-optimized video streaming utilities — use for frame buffering, pixel streaming control, or ROI extraction in FPGA video pipelines | Utilities | Vision HDL Toolbox |

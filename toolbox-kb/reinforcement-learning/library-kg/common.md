# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Execute a trained reinforcement learning policy during simulation — use for deploying RL-trained controllers in Simulink for inference without further training | Policy | Reinforcement Learning |
| Train or execute a reinforcement learning agent interacting with a Simulink environment — use for learning optimal control policies through simulation-based training | RL Agent | Reinforcement Learning |

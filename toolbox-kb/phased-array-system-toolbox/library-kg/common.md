# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Apply conventional phase-shift beamforming to steer the array toward a specified direction | Phase Shift Beamformer | Phased Array System Toolbox |
| Detect targets using constant false alarm rate processing with adaptive threshold estimation | CFAR Detector | Phased Array System Toolbox |
| Apply matched filtering to maximize SNR of a known radar waveform in received data | Matched Filter | Phased Array System Toolbox |
| Compute range-Doppler map from pulse data for simultaneous range and velocity estimation | Range Doppler Response | Phased Array System Toolbox |
| Estimate spatial spectrum using the MUSIC algorithm for high-resolution DOA estimation | MUSIC Spectrum | Phased Array System Toolbox |
| Model narrowband signal propagation through free space with path loss and time delay | Free Space | Phased Array System Toolbox |
| Model platform motion to provide position, velocity, and orientation for moving sensors or targets | Motion Platform | Phased Array System Toolbox |
| Collect narrowband signals across array elements with spatial phase shifts from incident direction | Narrowband Receive Array | Phased Array System Toolbox |
| Model a receiver front-end preamplifier with gain, noise figure, and dynamic range limits | Receiver Preamp | Phased Array System Toolbox |
| Model a radar or communications transmitter with specified peak power and gain | Transmitter | Phased Array System Toolbox |
| Generate a frequency-modulated continuous wave signal for automotive or short-range radar | FMCW Waveform | Phased Array System Toolbox |
| Generate a linear frequency-modulated chirp pulse for radar range resolution | Linear FM Waveform | Phased Array System Toolbox |

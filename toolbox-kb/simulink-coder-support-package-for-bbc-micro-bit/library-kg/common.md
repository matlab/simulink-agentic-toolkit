# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read 3-axis acceleration data from the BBC micro:bit onboard accelerometer — use for tilt detection, motion sensing, or gesture recognition projects | Accelerometer | Simulink Coder Support Package for BBC micro:bit |
| Read button press state on the BBC micro:bit — use for detecting user input from the two onboard pushbuttons | Button | Simulink Coder Support Package for BBC micro:bit |
| Control the 5x5 LED matrix on the BBC micro:bit — use for displaying patterns, scrolling text, or visual indicators | LED | Simulink Coder Support Package for BBC micro:bit |

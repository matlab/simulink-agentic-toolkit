# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Attach a virtual camera sensor in the 3D simulation scene — use for generating synthetic camera images for perception algorithm development | Simulation 3D Camera | Offroad Autonomy Library |
| Attach a virtual lidar sensor in the 3D simulation scene — use for generating synthetic point clouds for offroad perception testing | Simulation 3D Lidar | Offroad Autonomy Library |
| Configure the 3D simulation environment and scene — use for selecting terrain, weather, and lighting conditions for offroad simulation | Simulation 3D Scene Configuration | Offroad Autonomy Library |
| Model-predictive path integral controller for Ackermann-steered vehicles — use for sampling-based trajectory optimization in offroad navigation | Ackermann MPPI Controller | Offroad Autonomy Library |

# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read a data sample from a DDS (Data Distribution Service) topic — use to subscribe to real-time distributed data in systems that communicate over OMG DDS middleware | Take DDS Sample | DDS Blockset |
| Publish a data sample to a DDS (Data Distribution Service) topic — use to broadcast real-time data from Simulink to other DDS participants in a distributed system | Write DDS Sample | DDS Blockset |

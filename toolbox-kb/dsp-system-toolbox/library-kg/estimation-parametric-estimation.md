# Estimation parametric estimation

Use these blocks for estimation parametric estimation.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Burg AR Estimator | dspparest3/Burg AR Estimator | R2023a+ | Frame-based parametric AR estimation using the Burg maximum entropy method. Outputs AR model coefficients A and/or reflection coefficients K, plus the model gain, G. |
| Covariance AR Estimator | dspparest3/Covariance AR Estimator | R2023a+ | Frame-based parametric AR estimation using the Covariance method. The AR model coefficients are given in A and the gain is given in G. |
| Modified Covariance AR Estimator | dspparest3/Modified Covariance AR Estimator | R2023a+ | Frame-based parametric AR estimation using the Modified Covariance method. The AR model coefficients are given in A and the gain is given in G. |

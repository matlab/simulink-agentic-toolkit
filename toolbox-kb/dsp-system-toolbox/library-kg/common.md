# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Design and apply digital filters (FIR, IIR, adaptive, multirate) to signals — use for noise removal, band selection, decimation, or interpolation in signal processing pipelines | Filtering | DSP System Toolbox |
| Apply signal operations like convolution, correlation, interpolation, and zero-crossing detection — use for time-domain signal manipulation and feature extraction | Signal Operations | DSP System Toolbox |
| Display and log signals with scopes, spectrum analyzers, and array plots — use for real-time visualization and analysis of signal processing results | Sinks | DSP System Toolbox |
| Generate test signals (sine, chirp, noise, pulse) and read from audio/file sources — use as inputs to DSP processing chains for development and testing | Sources | DSP System Toolbox |
| Compute running statistics (mean, variance, histogram, min/max) on streaming signals — use for online signal monitoring and statistical characterization | Statistics | DSP System Toolbox |
| Apply spectral and time-frequency transforms (FFT, DCT, Hilbert, spectrogram) — use to convert signals between time and frequency domains for analysis or processing | Transforms | DSP System Toolbox |

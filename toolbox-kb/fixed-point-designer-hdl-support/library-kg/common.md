# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Compute square root using CORDIC for HDL — use for implementing sqrt in FPGA without multipliers | CORDIC Square Root HDL Optimized | Fixed-Point Designer HDL Support |
| Divide real numbers optimized for HDL — use for general-purpose fixed-point division on FPGA | Real Divide HDL Optimized | Fixed-Point Designer HDL Support |
| Solve real linear systems with burst QR — use for FPGA-based overdetermined system solving | Real Burst Matrix Solve Using QR Decomposition | Fixed-Point Designer HDL Support |
| Compute SVD of non-square matrices for HDL — use for FPGA-based singular value decomposition of rectangular matrices | Non-Square Jacobi SVD HDL Optimized | Fixed-Point Designer HDL Support |

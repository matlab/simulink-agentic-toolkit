# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Read analog input channels via the ADC peripheral on Renesas RA — use for sampling sensor voltages or analog signals in embedded control applications | Analog To Digital Converter | Embedded Coder Support Package for Renesas RA Microcontrollers |
| Read digital GPIO pin states on Renesas RA — use for reading switches, encoders, or digital sensor inputs | Digital Port Pins Read | Embedded Coder Support Package for Renesas RA Microcontrollers |
| Write digital GPIO pin states on Renesas RA — use for controlling LEDs, relays, or digital output signals | Digital Port Pins Write | Embedded Coder Support Package for Renesas RA Microcontrollers |
| Generate PWM signals on Renesas RA timer outputs — use for motor control, LED dimming, or servo positioning | PWM Output | Embedded Coder Support Package for Renesas RA Microcontrollers |
| Generate three-phase PWM waveforms on Renesas RA — use for driving BLDC motors or three-phase inverters in motor control applications | Three-Phase PWM | Embedded Coder Support Package for Renesas RA Microcontrollers |

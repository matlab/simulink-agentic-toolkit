# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Model acoustic volume compliance — use for representing enclosed air volumes that store acoustic energy as pressure | Acoustic Compliance | Simscape Acoustics |
| Model acoustic mass or inertance — use for representing the inertia of air in tubes or ports | Acoustic Inertance | Simscape Acoustics |
| Define the acoustic reference node — use as the ground equivalent in acoustic circuit networks | Acoustic Reference | Simscape Acoustics |
| Model acoustic resistance — use for representing viscous and thermal losses in acoustic passages | Acoustic Resistance | Simscape Acoustics |
| Measure acoustic pressure between two nodes — use for monitoring pressure at any point in the acoustic network | Pressure Sensor | Simscape Acoustics |
| Electrodynamic loudspeaker model — use for simulating standard moving-coil speaker transduction and response | Moving Coil Speaker | Simscape Acoustics |

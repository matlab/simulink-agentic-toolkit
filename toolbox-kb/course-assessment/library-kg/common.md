# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Provide a constant value for course assessment grading templates — use as a placeholder signal source in auto-graded student assignment models | Constant | Course Assessment |
| Terminate an unconnected signal in course assessment models — use to suppress unconnected port warnings in auto-graded student assignment templates | Terminator | Course Assessment |

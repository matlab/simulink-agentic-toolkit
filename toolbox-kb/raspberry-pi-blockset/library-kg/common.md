# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Access basic I/O on Raspberry Pi — use for GPIO read/write, PWM output, or general-purpose digital interfacing on Pi boards | Basic | Raspberry Pi Blockset |
| Access communication interfaces on Raspberry Pi — use for I2C, SPI, UART, or serial communication with external devices | Communication | Raspberry Pi Blockset |
| Access external sensor modules on Raspberry Pi — use for reading temperature, humidity, distance, or other sensor data from connected peripherals | Sensors | Raspberry Pi Blockset |

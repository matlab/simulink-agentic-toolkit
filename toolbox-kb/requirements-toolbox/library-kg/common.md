# Common Blocks

Prefer these blocks when their intent matches the user request.

| Intent | Preferred Block | Library |
|---|---|---|
| Author and manage formal requirements directly in the model as a table of preconditions, postconditions, and assumptions — use to capture logical/textual requirements, generate test assessments, and link requirements to design for verification. | Requirements Table | Requirements Toolbox |
| Display the requirements linked to the current model or subsystem inside the diagram — use to surface traceability information where the design lives. | System Requirements | Requirements Toolbox |

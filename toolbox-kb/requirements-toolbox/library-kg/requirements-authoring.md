# Requirements authoring

Use these blocks for requirements authoring.

## Recommended Blocks

| Block | ReferenceBlock | Since | Intent |
|---|---|---|---|
| Requirements Table | reqmanage/Requirements Table | R2023a+ | Author and manage formal requirements directly in the model as a table of preconditions, postconditions, and assumptions — use to capture logical/textual requirements, generate test assessments, and link requirements to design for verification. |
| System Requirements | reqmanage/System Requirements | R2023a+ | Display the requirements linked to the current model or subsystem inside the diagram — use to surface traceability information where the design lives. |

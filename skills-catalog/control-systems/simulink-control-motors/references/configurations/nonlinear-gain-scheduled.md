# Configuration: Nonlinear Gain-Scheduled FOC (FEM-PMSM)

**Motor:** Simscape FEM-Parameterized PMSM (with flux linkage tables)
**Control:** Gain-scheduled PI current loops + LUT-based control reference
**Use case:** High-performance drives with saturation-aware control

## Architecture
```
Speed_Ref → Speed_PI → Tref → LUT Control Reference(id*,iq*) ← speed
id*/iq* - id/iq → Gain-Scheduled PI_d/PI_q(Kp(id,iq), KiTs(id,iq)) → Vdq
Vdq + FF(ωe*λd, ωe*λq from LUT) → InvPark → PWM → Avg-Value Inverter → FEM-PMSM
```

## Gain Scheduling (Key Innovation)
```matlab
% Incremental inductance from flux tables:
Ld_inc(i,j) = gradient(FluxD(:,j), idVec);   % ∂λd/∂id
Lq_inc(i,j) = gradient(FluxQ(i,:), iqVec);   % ∂λq/∂iq

% PI gains indexed by operating point (id, iq):
BW_i = 1 / (4 * Ts);
Kp_d_LUT = Ld_inc * BW_i;
Kp_q_LUT = Lq_inc * BW_i;
Ki_d_LUT = Rs * BW_i * ones(nId, nIq);
Ki_q_LUT = Rs * BW_i * ones(nId, nIq);
KiTs_d_LUT = Ki_d_LUT * Ts;
KiTs_q_LUT = Ki_q_LUT * Ts;
```

## Why Incremental (Not Apparent) Inductance?
| Type | Definition | Use |
|---|---|---|
| Apparent | Ld_app = λd/id | Steady-state flux calculation |
| Incremental | Ld_inc = ∂λd/∂id | **PI controller plant model** |

PI regulates *changes* in current. Plant gain for perturbations = incremental inductance.
At heavy saturation: `Ld_inc << Ld_app` → gains must be larger.

## LUT Control Reference
- Generated by `mcb.generateMotorLUT(motor, inverter, 'idiqLUTs')`
- Provides optimal id*/iq* as function of (torque_ref, speed)
- Handles MTPA + field weakening via precomputed trajectories

## Feed-Forward (Nonlinear)
```matlab
Vd_ff = -ωe * λq(id,iq)   % From flux LUT (not Lq*iq!)
Vq_ff = ωe * λd(id,iq)    % From flux LUT (not Ld*id+FluxPM!)
```

## Simscape FEM-PMSM Integration
- Uses Average-Value Inverter pattern (duty → scale → CVS3 → Motor)
- Solver: ode14x (implicit, required for Simscape)
- Angle: IRMS → radians → Gain(1/(2*pi)) → Mech-to-Elec (PU mode)
- Current: Three-Phase Current Sensor → Goto(Iabc)

## 2-D Lookup Tables in Simulink
- Input 1: id_meas (d-axis current feedback)
- Input 2: iq_meas (q-axis current feedback)
- Output: Kp or KiTs at current operating point
- Feed into PI Controller external gain ports

## Default Motor
- FEM-PMSM with flux tables covering id/iq grid (15×15 typical)
- Reference: PMSMGainSchedulingModel.slx (mcb-ex93682944)

## Things to Avoid
- DO NOT use apparent inductance for PI gains — wrong at saturation
- DO NOT forget flux table extrapolation check — causes solver divergence
- DO NOT use fixed PI gains with nonlinear motor — oscillation at high saturation
- DO NOT use Ld*id formula for FF with nonlinear motor — use λd(id,iq) LUT

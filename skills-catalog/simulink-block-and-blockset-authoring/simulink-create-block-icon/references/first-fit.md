# First Fit

Display elements that fit the size of the icon. You can create a block icon that
dynamically changes as you resize the block: the representation that fits within the
new size is displayed as the block icon. The image is neither shrunk nor cropped —
instead a clear and readable version of the icon always appears, regardless of the
size of the block.

To create it, select the elements you want and choose **Convert to First Fit**. This
groups the selected elements so that only the elements that fit the current icon size
are displayed; as the block gets smaller, a simpler representation takes over.

**When to use it**
- Keep an icon legible across a wide range of block sizes, from large to very small.
- Offer a detailed appearance at full size that falls back to a compact symbol when
  space is tight.

**Examples**
- A block that shows a full label at large sizes, an abbreviation at medium sizes,
  and a single symbol when small.
- A detailed diagram that switches to a minimal marker when the block is shrunk.

# Port Labels

Bind a label to a specific port on a block icon and keep it anchored there. You choose
the port — for example, the first left port — and the label stays attached to it, so it
tracks that port as you resize or modify the block. You can optionally offset the label
from the port. (A port is a visual reference for the block's inputs and outputs; labeling
it does not add a real block port.)

**When to use it**
- Label a known, fixed port with a meaningful name, such as `in`, `out`, `clk`, or `rst`.
- Anchor a marker or small graphic to a particular port so it stays with that port.

**Examples**
- An `in` label on the first input port and an `out` label on the first output port.
- `+` and `-` labels bound to the two input ports of a summing block.

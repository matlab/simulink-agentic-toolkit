# Relative Position

Position elements relatively using relative positioning. You can anchor icon elements
at a specific position, or relative to other elements or the block boundary, so the
layout holds together as the block changes.

Relative positioning reduces manual adjustments when you resize or modify icons and
helps maintain consistent alignment and spacing. You choose what to position, what to
position it relative to (another element or the block boundary), and an optional
offset.

**When to use it**
- Keep a label centered on a shape, or pinned to an edge, no matter how the block is
  resized.
- Maintain even padding or spacing between elements without hand-tuning coordinates.
- Anchor elements to the block boundary so they track its edges.

**Examples**
- A caption that stays centered under a box as the block grows or shrinks.
- A rectangle that keeps a fixed margin from all four edges of the block.
- Two elements kept a set distance apart regardless of block size.

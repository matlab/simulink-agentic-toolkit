# Equation

Write equations on the icon using LaTeX markup. The equation tool is similar to the
equation tool in MATLAB and Simulink, and renders your markup as clean math graphics
on the block face.

Use it when a block is best described by a formula rather than a plain label — a
transfer function, a summation, or any expression that reads more clearly as
typeset math.

**When to use it**
- Show the mathematical operation a block performs directly on its icon.
- Present a transfer function, integral, or matrix that would be awkward as ordinary
  text.

**Examples**
- An integrator block displaying `1/s` as a typeset fraction.
- A block showing a summation or a time-delay term such as `e^{-sT}`.

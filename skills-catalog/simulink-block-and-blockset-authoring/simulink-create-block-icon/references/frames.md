# Frames

A frame is the block's outer boundary shape on the Simulink canvas. By default a masked
block uses a rectangular frame. You can change it to another shape, or turn the frame off
so the icon sits directly on the canvas with no border.

**Available shapes:** rectangle (default), circle, capsule, triangle, trapezium, hexagon,
or none.

**When to use it**
- Match the outline to the block's role — for example, a triangle for a gain-style block,
  a circle or capsule for a rounded component, or no frame for a purely decorative/logo icon.
- Otherwise keep the default rectangle; only change the frame when a different outline
  communicates something useful.

**Examples**
- A gain block drawn inside a triangular frame.
- A sensor block with a circular frame.
- A logo icon with the frame turned off so only the artwork shows.

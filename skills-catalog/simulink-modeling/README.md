# Simulink Modeling

Skills for building and configuring Simulink models — block configuration, custom code integration, and model construction patterns that use base Simulink (no additional toolbox required).

| Skill | Description |
|-------|---------------------------|
| `simulink-use-c-function-block` | Configure Simulink C Function blocks programmatically using the SymbolSpec API for integrating C/C++ code into models |
